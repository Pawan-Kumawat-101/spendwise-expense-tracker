# SpendWise – Personal Expense Tracker

A responsive expense tracking web app built with HTML5, CSS3, JavaScript (ES6) and Chart.js.

## Features
- Add / delete income and expense transactions
- Monthly budget with progress alert (green, amber, red)
- Savings rate and top-spending-category insight
- Doughnut chart (spending by category) and bar chart (last 6 months income vs expense)
- Filter by month, category and keyword search
- Export filtered transactions to CSV
- Data saved in the browser using localStorage
- Dark / light theme, mobile-first layout with floating add button

## Tech Stack
HTML5, CSS3 (Grid, Flexbox, CSS variables), JavaScript (ES6), Chart.js, localStorage

## How to Run
1. Download or clone this repository
2. Open `index.html` in any browser (internet needed once to load Chart.js)
